# Описание проекта Vibe Workflow

Этот проект реализует движок для выполнения workflow-процессов с поддержкой блоков, координации и событий.
Структура проекта включает приложения, документацию и основные пакеты.

---

## Файлы

- [`README.md`](README.md)
  Основное описание проекта, инструкции по запуску и использованию.

- [`package.json`](package.json)
  Метаданные проекта: зависимости, скрипты сборки и экспорт основного модуля.

- [`tsconfig.json`](tsconfig.json)
  Конфигурация TypeScript для проекта.

- [`bunconfig.toml`](bunconfig.toml)
  Конфигурация для сборки и запуска с помощью Bun.

- [`bun.lock`](bun.lock)
  Замороженные зависимости для Bun.

- [`dir_list.txt`](dir_list.txt)
  Список всех директорий проекта (для справки).

- [`gitignore`](.gitignore)
  Список игнорируемых файлов и папок для git.

---

## Подпапки

- [`apps/`](apps/DESCRIPTION.md)
  Приложения и CLI-инструменты для запуска и тестирования workflow.

- [`docs/`](docs/DESCRIPTION.md)
  Документация по проекту, API и примеры использования.

- [`packages/`](packages/DESCRIPTION.md)
  Основные пакеты: shared типы и утилиты (`shared`), ядро движка (`workflow`).
