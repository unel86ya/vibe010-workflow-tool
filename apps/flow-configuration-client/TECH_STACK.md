# apps/flow-configuration-client: Технологии стека

## Языки программирования
- TypeScript (строгая типизация, современные возможности JS)

## Система сборки и запуска
- Vite (модульная сборка и разработка фронтенда)

## Фронтенд-фреймворк
- Svelte 5+ (компонентный UI)

## Стилизация
- TailwindCSS (модульная CSS-фреймворк)

## Тестирование
- vitest (универсальный тест-раннер)
