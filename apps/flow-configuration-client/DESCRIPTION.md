# Описание папки apps/flow-configuration-client/

Папка apps/flow-configuration-client/ содержит клиентскую часть конфигуратора потоков.
Здесь реализованы интерфейс и логика взаимодействия с сервером для создания, редактирования и просмотра конфигураций потоков данных.
Клиент предоставляет удобный UI для построения и тестирования схем обработки данных, а также интеграцию с основным CLI-приложением.

## Файлы
- package.json — зависимости и скрипты приложения
- README.md — краткая документация
- tsconfig.json — конфигурация TypeScript

## Подпапки
- src/ — исходный код клиентского приложения
