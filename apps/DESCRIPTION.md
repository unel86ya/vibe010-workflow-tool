# Описание папки apps/

В этой папке находятся основные приложения проекта.

## Файлы
- .DS_Store

## Подпапки

### cli/
Папка содержит CLI-приложение для управления потоками. Включает основной исполняемый файл, файлы конфигурации (package.json, tsconfig.json), тестовый YAML-файл (test-flow.yml) и исходный код в подпапке src/.
В src/ реализованы основные команды, блоки (compute, effects, events) и подсистема для работы с потоками.

Подробности см. в ./cli/DESCRIPTION.md.

### flow-configuration-client/
Папка содержит фронтенд-приложение на Svelte/Vite для конфигуратора потоков. Включает файлы конфигурации (package.json, tsconfig.json, vite.config.ts), статические импорты, скрипты сборки и сервера, а также исходный код в src/.
В src/ реализованы компоненты интерфейса, сервисы API, маршруты и логика взаимодействия с сервером.

Подробности см. в ./flow-configuration-client/DESCRIPTION.md.

### flow-configuration-server/
Папка содержит серверную часть конфигуратора потоков. Включает файлы конфигурации (package.json, tsconfig.json) и исходный код в src/.
В src/ реализован основной серверный модуль (index.ts), отвечающий за хранение и предоставление конфигураций потоков.

Подробности см. в ./flow-configuration-server/DESCRIPTION.md.
