# Описание папки apps/cli/src/

Папка apps/cli/src/ содержит исходный код CLI-приложения для управления workflow-потоками.
Здесь реализован точка входа приложения (cli.ts), инициализация движка выполнения потоков, регистрация команд управления и основной экспорт (index.ts).
В подпапках blocks/ и commands/ размещены реализации всех блоков и команд, используемых CLI для построения и запуска потоков данных.

## Файлы

- **cli.ts** — точка входа приложения, инициализирует движок FlowEngine, загружает все блоки из подпапки blocks/ и регистрирует команды управления потоками через commander.
- **index.ts** — основной экспорт и инициализация, предоставляет глобальный доступ к движку FlowEngine и экспортирует функции для запуска CLI.

## Подпапки

- **blocks/** — реализация всех блоков (события, эффекты, вычисления), используемых в потоках данных.
- **commands/** — команды управления потоками, реализующие запуск, тестирование и настройку схем обработки данных.

Подробности смотрите в следующих файлах:
- ./blocks/DESCRIPTION.md
- ./commands/DESCRIPTION.md
