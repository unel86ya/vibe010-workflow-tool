# Описание папки apps/cli/src/blocks/compute/

В этой папке находятся реализации вычислительных блоков (compute), которые выполняют обработку и преобразование данных в потоках.

## Файлы

- **const-block.ts**
  Реализует блок для объявления и использования констант в потоке.
  Позволяет задавать неизменяемые значения, которые могут использоваться в последующих вычислениях.

- **function-compute.ts**
  Реализует блок для вызова пользовательских функций и встроенных вычислений.
  Позволяет выполнять произвольные вычисления, передавая входные значения и получая результат для дальнейшей обработки.

- **variable-block.ts**
  Реализует блок для объявления, изменения и использования переменных в потоке.
  Позволяет хранить и модифицировать значения между шагами вычислений.

Инструкции для дочерних папок отсутствуют.
