    # Описание папки apps/cli/src/blocks/effects/

В этой папке находятся реализации эффектов (effects), отвечающих за побочные действия в потоках: вывод в консоль, сетевые запросы, работа с файлами и изменение переменных.

## Файлы

- **console-effect.ts**
  Эффект для вывода сообщений в консоль (stdout/stderr).
  Позволяет логировать промежуточные значения или ошибки прямо в терминал.

- **fetch-effect.ts**
  Эффект для выполнения HTTP-запросов (GET, POST и др.) к внешним API.
  Используется для получения или отправки данных из/в сторонние сервисы.

- **file-read-effect.ts**
  Эффект для асинхронного чтения данных из файла.
  Поддерживает чтение текстовых и бинарных файлов по абсолютному или относительному пути.

- **file-write-effect.ts**
  Эффект для асинхронной записи данных в файл.
  Позволяет сохранять результаты вычислений или промежуточные данные на диск.

- **variable-effect.ts**
  Эффект для изменения значения переменной в потоке.
  Используется для обновления состояния переменных между шагами вычислений.

Инструкции для дочерних папок отсутствуют.
