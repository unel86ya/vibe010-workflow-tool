# Описание папки apps/cli/src/blocks/

В этой папке находятся реализации блоков для потоков: вычислительных (compute), эффектов (effects) и событий (events).

## Назначение подпапок

- **compute/**
  Вычислительные блоки: реализуют логику обработки данных, преобразования и агрегации.

- **effects/**
  Блоки эффектов: отвечают за побочные эффекты (например, отправка HTTP-запросов, запись в базу данных).

- **events/**
  Блоки событий: обрабатывают внешние события (например, пользовательские действия, таймеры).

Инструкции для дочерних папок см. в их DESCRIPTION.md.
