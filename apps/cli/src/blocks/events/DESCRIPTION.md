# Описание папки apps/cli/src/blocks/events/

В этой папке находятся реализации событий (events), которые инициируют выполнение потоков по внешним или внутренним триггерам: действия пользователя и таймеры.

## Файлы

- **action-event.ts**
  Событие, запускающее поток по пользовательскому действию (например, по команде в CLI или нажатию кнопки).
  Используется для реакции на ввод пользователя или внешние команды.

- **timer-event.ts**
  Событие, запускающее поток по истечении заданного интервала времени (таймер).
  Позволяет реализовать периодические или отложенные задачи.

Инструкции для дочерних папок отсутствуют.
