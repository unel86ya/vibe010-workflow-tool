# Описание папки apps/cli/

Папка apps/cli/ содержит CLI-приложение для запуска, тестирования и управления workflow-потоками данных.
CLI инициализирует движок выполнения потоков (FlowEngine), загружает все реализованные блоки (события, эффекты, вычисления) из подпапки ./blocks/ и предоставляет команды для запуска, тестирования и настройки схем обработки данных из командной строки.
CLI не взаимодействует с серверной частью конфигуратора потоков — он работает автономно по локальной конфигурации.
Приложение поддерживает загрузку внешних блоков через опцию --blocks-path, подробное логирование с --verbose и позволяет запускать потоки по YAML-конфигу.

## Файлы

- **package.json** — файл зависимостей и скриптов приложения, определяет используемые пакеты и точки входа.
- **README.md** — краткая документация по установке, запуску и основным командам CLI.
- **test-flow.yml** — пример YAML-конфигурации потока для тестирования и демонстрации возможностей CLI.
- **tsconfig.json** — конфигурация TypeScript для сборки и проверки типов исходного кода.

## Подпапки

- **src/** — исходный код CLI-приложения, реализующий инициализацию движка, загрузку блоков и команды управления потоками.
