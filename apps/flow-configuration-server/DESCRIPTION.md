# Описание папки apps/flow-configuration-server/

Папка apps/flow-configuration-server/ содержит серверную часть конфигуратора потоков.
Здесь реализованы REST API и бизнес-логика для хранения, обработки и управления конфигурациями потоков данных.
Сервер обеспечивает хранение схем, обработку запросов от клиентского приложения и интеграцию с основным CLI-приложением.

## Файлы
- package.json — зависимости и скрипты приложения
- README.md — краткая документация
- tsconfig.json — конфигурация TypeScript

## Подпапки
- src/ — исходный код серверного приложения
