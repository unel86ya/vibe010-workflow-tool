## Работа с файлами
- При работе с файлами различайте:
  - **Внешняя файловая система** (например, пользовательские директории, `/tmp`, `/home`): используйте абсолютные пути или относительные к рабочей директории.
  - **Файлы внутри собранного бинарника** (например, шаблоны, конфиги, встроенные assets): используйте `import` для импорта файлов как строковых ресурсов (`import template from './template.txt'`), не пытайтесь читать их через `fs.readFile` — они недоступны как обычные файлы после bundling.
- Для доступа к встроенным ресурсам используйте импорт как строковых литералов или буферов.
- Для пользовательских файлов всегда проверяйте права доступа и корректность путей.

- Если одна и та же логика должна работать и с внешними, и с внутренними файлами:
  - Разделяйте процессинг и чтение/запись:
    • Реализуйте отдельную функцию-обёртку для получения содержимого файла (строка или буфер), которая возвращает данные из внешнего файла или из встроенного ресурса.
    • Логика обработки принимает строку или буфер и не зависит от источника данных.
  - Пример:
    ```ts
    // Чтение из внешнего файла или встроенного ресурса
    async function readFileContent(pathOrResource: string): Promise<string> {
      if (isExternalPath(pathOrResource)) {
        return Bun.file(pathOrResource).text();
      } else {
        // pathOrResource — это имя встроенного ресурса
        return import(`./resources/${pathOrResource}.txt`).then(m => m.default);
      }
    }
    // Логика обработки
    function processFileContent(content: string) {
      // ...
