## Общие правила (см. apps/CODE_STYLE.md)
- ES-модули (`import`/`export`)
- SOLID и декомпозиция модулей, классов и функций
- Комментарии: описание функции или объяснение неочевидного решения
- Используйте только ES-модули (`import`/`export`).
- Один экспорт на файл (если не модуль).
- Имя файла совпадает с экспортируемым именем (например, `cli.ts` → `export function runCli() { ... }`).
