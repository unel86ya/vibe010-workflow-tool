# Описание папки shared/src

Папка shared/src содержит исходный код общих типов и утилит для проекта Vibe Workflow. Здесь реализованы основные типы для блоков, координаторов, потоков и среды выполнения, а также вспомогательные функции для работы с ошибками и переменными окружения.

## Файлы

- [`index.ts`](index.ts): Экспорт основных типов и утилит из папки shared/src.

## Подпапки

- [`types/`](types/DESCRIPTION.md): Определения типов для блоков, координаторов, потоков и среды выполнения.
- [`utils/`](utils/DESCRIPTION.md): Вспомогательные функции для работы с ошибками и переменными окружения.
