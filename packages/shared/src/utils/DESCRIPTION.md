# Описание папки shared/src/utils

Папка shared/src/utils содержит вспомогательные утилиты для работы с переменными окружения и обработки ошибок в общих модулях.

## Файлы

- [`env-utils.ts`](env-utils.ts): Утилиты для работы с переменными окружения (получение, парсинг, валидация).
- [`error-utils.ts`](error-utils.ts): Вспомогательные функции для создания и обработки пользовательских ошибок (координаторов, блоков, потоков).
- [`index.ts`](index.ts): Экспорт основных функций и типов из папки utils.
