# Описание папки shared/src/types

Папка shared/src/types содержит основные типы и интерфейсы для работы с блоками, потоками и средой выполнения в общих модулях.

## Файлы

- [`block.ts`](block.ts): Определения интерфейсов и типов для пользовательских блоков (BlockDefinition, BlockInput/Output).
- [`coordinator.ts`](coordinator.ts): Типы для координатора потоков (CoordinatorConfig, CoordinatorState).
- [`flow.ts`](flow.ts): Интерфейсы и типы для описания потоков (FlowDefinition, FlowNode).
- [`runtime.ts`](runtime.ts): Типы для среды выполнения (RuntimeContext, ExecutionContext).
