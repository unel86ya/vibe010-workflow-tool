# Описание пакета packages/shared

Этот пакет содержит общие типы и утилиты для работы с workflow-блоками и координаторами.
Используется как зависимость в других частях проекта Vibe Workflow.

---

## Файлы

- [`package.json`](package.json)
  Метаданные пакета: зависимости, скрипты сборки и экспорт основного модуля.

---

## Подпапки

- [`src/`](src/DESCRIPTION.md)
  Исходный код пакета: типы (`types/`), утилиты (`utils/`) и основной экспорт (`index.ts`).
