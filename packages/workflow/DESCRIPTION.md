# Описание пакета packages/workflow

Этот пакет реализует ядро движка Vibe Workflow: выполнение блоков, управление потоками, координацию и обработку событий.
Используется как основной движок для запуска и управления workflow-процессами.

---

## Файлы

- [`package.json`](package.json)
  Метаданные пакета: зависимости, скрипты сборки и экспорт основного модуля.

---

## Подпапки

- [`src/`](src/DESCRIPTION.md)
  Исходный код движка: ядро выполнения (`core/`), утилиты (`utils/`) и основной экспорт (`index.ts`).
