# Описание папки workflow/src/core

Папка workflow/src/core содержит основные компоненты ядра движка Vibe Workflow: загрузчики блоков, регистраторы, координаторы, парсеры потоков и движок среды выполнения.

## Файлы

- [`block-loader.ts`](block-loader.ts): Загружает пользовательские блоки из файловой системы или пакетов, проверяет их корректность и регистрирует в системе.
- [`block-registry.ts`](block-registry.ts): Хранит и управляет всеми зарегистрированными блоками, обеспечивает быстрый поиск по имени и версии.
- [`coordinator.ts`](coordinator.ts): Управляет выполнением потоков, распределяет задачи между блоками, отслеживает зависимости и состояние выполнения.
- [`flow-parser.ts`](flow-parser.ts): Парсит YAML-описания потоков, валидирует структуру, преобразует в внутреннее представление для выполнения.
- [`runtime-engine.ts`](runtime-engine.ts): Исполняет потоки, запускает блоки в нужном порядке, управляет контекстом выполнения и обработкой ошибок.
