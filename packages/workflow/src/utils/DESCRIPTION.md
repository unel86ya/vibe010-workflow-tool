# Описание папки workflow/src/utils

Папка workflow/src/utils содержит вспомогательные утилиты для workflow-движка: логирование, валидацию и работу с YAML.

## Файлы

- [`logger.ts`](logger.ts): Универсальный модуль логирования для workflow-движка, поддерживает уровни (debug, info, warn, error) и вывод в консоль/файл.
- [`validation.ts`](validation.ts): Инструменты валидации входных данных и структур потоков, реализуют проверки типов, обязательных полей и формата YAML.
- [`yaml-utils.ts`](yaml-utils.ts): Утилиты для сериализации/десериализации YAML-файлов, обеспечивают безопасное чтение и запись потоковых описаний.
