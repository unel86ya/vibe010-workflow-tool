# Описание папки workflow/src

Папка workflow/src содержит основной исходный код движка Vibe Workflow: точку входа и модули для выполнения потоков.

## Файлы

- [`index.ts`](index.ts): Точка входа workflow-движка, экспортирует основные API для запуска и управления потоками.

## Подпапки

- [`core/`](core/DESCRIPTION.md): Ядро движка — загрузка блоков, парсинг потоков, координатор выполнения.
- [`utils/`](utils/DESCRIPTION.md): Вспомогательные утилиты — логирование, валидация, работа с YAML.
